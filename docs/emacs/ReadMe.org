* What is this?

Comprehensive documentation of the partial restoration and modification of my 1983 Toyota Pickup 4WD. She's a 50/50 trail rig and daily driver.

** Project Overview
   - Vehicle: 1983 Toyota Pickup 4WD
   - Major Project: CBEA 2.0 TDI Engine Swap from 8P Audi
   - Goals: Reliable daily driver with solid off-road capability and better power/economy

** Key Components
   - Engine: CBEA 2.0 TDI (toooned!)
   - Transmission: R151F
   - Other Upgrades: BMW CP3 HPFP, Fast Forward wiring, EHPS
